# 🐣 Chicken (แอปบันทึกรายรับรายจ่าย กิจกรรมเลี้ยงไก่ไข่)

เว็บแอปพลิเคชันสำหรับบันทึกรายรับ-รายจ่าย **"กิจกรรมเลี้ยงไก่ไข่" โรงเรียนวัดหนองตะเฆ่** ออกแบบสำหรับใช้งานบนมือถือได้อย่างสะดวก รวดเร็ว และเป็นระเบียบ ด้วยโทนสีเหลือง-ขาวพาสเทล พร้อมฟอนต์ **Mali** สำหรับหน้าจอใช้งาน และฟอนต์ **Sarabun (สารบรรณ)** สำหรับระบบพิมพ์รายงานเอกสารทางการ รองรับการทำงานแบบ **Dual Mode** (รันตรงบน Google Apps Script หรือรันผ่าน GitHub Pages เชื่อมต่อฐานข้อมูล Google Sheets แบบเรียลไทม์) และรองรับมาตรฐาน **PWA (Progressive Web App)** เพิ่มลงหน้าจอโฮมบน iPhone / iPad / Android ได้เต็มจอ

🌐 **GitHub Pages URL:** [https://bosu-nsoq.github.io/wntk-chicken/](https://bosu-nsoq.github.io/wntk-chicken/)

---

## ✨ ฟีเจอร์เด่นของระบบ

1. **บันทึกรายรับและรายจ่ายรวดเร็ว:**
   - กรอกจำนวนเงินพร้อมเลือกรายการจากตัวเลือก หรือพิมพ์ระบุเองได้ทันที
   - มีหน้าต่างป๊อปอัพยืนยันความถูกต้องก่อนบันทึกข้อมูล
2. **สรุปยอดเงินคงเหลือเรียลไทม์:**
   - การ์ดแสดงยอดเงินคงเหลือสุทธิ (คำนวณจากรายรับ - รายจ่ายทั้งหมดในระบบ)
   - อัปเดตและเขียนยอดสุทธิลง Google Sheet อัตโนมัติ (ช่อง `F1` และ `F2`)
3. **ดึงรายการ Dropdown อัตโนมัติ:**
   - รายการใน Dropdown ดึงมาจากแถบ **Setting** ใน Google Sheets โดยตรง ทำให้แก้ไขหรือเพิ่มรายการได้ง่ายไม่ต้องแก้โค้ด
4. **ดูประวัติและจัดการรายการย้อนหลัง:**
   - ปุ่มลอย 📜 ด้านขวาบน แตะเพื่อเลื่อนเปิดถาดประวัติ 5 รายการล่าสุด
   - มีปุ่มถังขยะ 🗑️ ลบรายการที่ไม่ต้องการได้ทันที พร้อมคำนวณยอดเงินคงเหลือใหม่ให้อัตโนมัติ
5. **ระบบพิมพ์รายงานบัญชีทางการ (Print Report System) 🖨️:**
   - ปุ่มลอย 🖨️ ด้านซ้ายบน เปิดหน้าต่างกำหนดช่วงเวลาพิมพ์รายงาน:
     - **พิมพ์รายวัน**: ช่องเลือกวันที่ปฏิทินไทย **พ.ศ. (dd/mm/yyyy)**
     - **พิมพ์รายเดือน**: เลือกเดือน/ปี
     - **พิมพ์รายปี**: ระบุปี พ.ศ.
     - **พิมพ์ข้อมูลทั้งหมด**
   - เอกสารรายงานใช้ฟอนต์ **Sarabun (สารบรรณ)** ถูกต้องตามระเบียบแบบแผน
   - แสดง **ตราสัญลักษณ์โรงเรียนวัดหนองตะเฆ่**, สรุปยอดรวมรายรับ-รายจ่าย, ยอดเงินคงเหลือสุทธิ และช่องลงลายมือชื่อผู้จัดทำและครูที่ปรึกษากิจกรรม
6. **รองรับ PWA (Progressive Web App):**
   - ติดตั้ง Favicon และไอคอนแอปรูปไก่ `https://i.postimg.cc/V6DPphnK/chicken.png`
   - สามารถกด "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen) บน iOS/Android ใช้งานเหมือนแอปพลิเคชันจริง

```text
└── README.md           # เอกสารและคู่มือการใช้งานระบบ
```

## 🚀 วิธีติดตั้งบน Google Apps Script

1. เปิด **Google Sheets** ของกิจกรรมเลี้ยงไก่ไข่ขึ้นมา (ต้องมี Sheet ชื่อ `Data` และ `Setting`)
   - แถบ **`Data`**: เก็บข้อมูล [Date, Type, Amount, Note]
   - แถบ **`Setting`**: ใส่รายการตัวเลือกในคอลัมน์ A (เริ่มแถวที่ 1 ลงมา)
2. ไปที่เมนู **ส่วนขยาย (Extensions)** > **Apps Script**
3. คัดลอกโค้ดจากไฟล์ [`Code.gs`](./Code.gs) ไปวางแทนที่โค้ดเดิมใน `Code.gs`
4. กดเครื่องหมาย `+` ด้านซ้ายมือ เลือก **HTML** แล้วตั้งชื่อว่า `index`
5. คัดลอกโค้ดจากไฟล์ [`index.html`](./index.html) ไปวางในไฟล์ `index.html`
6. กดปุ่ม **บันทึกโครงการ (Save 💾)**
7. กดปุ่ม **การทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้รายการใหม่ (New deployment)**:
   - เลือกประเภท: **เว็บแอป (Web app)**
   - คำอธิบาย: `Chicken v1`
   - ปฏิบัติการในฐานะ: **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
8. กด **ทำให้ใช้งานได้ (Deploy)** และคัดลอก **URL เว็บแอป** เก็บไว้
